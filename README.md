# PANIT 판잇

사람을 잇고, 즐거운 판을 만들다. 운영사 ㈜메타매직.

마지막 12장 통합 기획과 파트너 Q&A를 바탕으로 만든 모바일 우선 홈페이지 1차 시안입니다.

## 현재 구현
- 반응형 메인, 공연·행사·예산 복합 필터와 초기화
- 구성 예시 상세 모달, 링크 공유(개인 실적 추적 아님)
- 파트너 활동 방식, 개인 엔터테인먼트 브랜드관 소개
- FAQ, 상담·가입·브랜드관 준비 상태 안내
- Cloudflare Workers Static Assets 배포 설정

## 아직 미구현
회원 인증, 개인 추천 추적, 실제 상담 저장, D1/R2, 고객·파트너·관리자 데이터 화면, 계약·정산, 결제. 시안에서 개인정보를 수집하지 않습니다.

예시 상품은 실제 판매·섭외를 보장하지 않습니다. 무료 5%·브랜드 10%는 제안 조건입니다. 브랜드관 개설비는 150,000원 + VAT 15,000원 = 165,000원이며 이용기간·갱신·환불은 확정 전입니다.

## 확인·개발
Node.js 환경에서 `npm run check`, 로컬 미리보기는 `npm run dev`.
외부 라이브러리·빌드 과정 없이 public 폴더를 정적 배포합니다.

## 휴대폰에서 Cloudflare 연결
1. Cloudflare 대시보드에 로그인합니다.
2. Workers & Pages에서 GitHub 저장소 연결을 선택합니다. 실제 메뉴 문구는 화면에 따라 확인합니다.
3. userface76/panit-platform 저장소, main 브랜치를 선택합니다.
4. Worker 이름은 panit-platform, 프로젝트 루트는 저장소 루트입니다.
5. 빌드 명령은 비워 두고 배포 명령은 `npx wrangler@4 deploy`로 지정합니다.
6. 배포 결과의 실제 workers.dev 주소를 확인합니다. 정식 도메인은 추후 연결합니다.

R2·D1·Turnstile·결제는 이 시안 배포에 필요하지 않습니다. 연결 후 별도 구현합니다. Worker 이름을 다르게 만들면 wrangler.jsonc의 name도 맞춰야 합니다. 비밀키·고객자료·계좌정보는 공개 저장소에 넣지 않습니다.

공식 문서: https://developers.cloudflare.com/workers/static-assets/
